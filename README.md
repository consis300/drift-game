# Sideways: JDM Drift

A 3D drifting game for phones, made with three.js. It runs in a web browser, with nothing to install.

- **Cars:** a 2020 Lexus IS300 F Sport (3.5L V6), an AE86 Trueno, a Silvia S15, an RX-7 FD, a Skyline GT-R R34 and a Supra A80
- **Tracks:** a club circuit, Tokyo docks at night, a mountain pass, a desert bowl and a frozen lake
- **Garage:** engine, turbo, tire, angle kit and weight upgrades, plus paint, wheel color, smoke color, underglow, spoiler, stripe and window tint options
- **Effects:** tire smoke, tire marks, burnouts, and engine sounds generated in the browser that follow rpm and gear
- **Touch controls:** steering arrows, gas, brake and e-brake

## Play
Open `index.html` in a browser. It needs an internet connection to load three.js. You can also turn on GitHub Pages for this repo and open it on your phone.

Keyboard controls: arrow keys or WASD to drive, Space for the e-brake, C to change the camera, P to pause.
